# Puti-AI 作文教學資料庫 📝

> 專為國小語文課堂、教室觸控大屏教學與備課列印打造的寫作素養全階梯引導系統。

🌐 **線上使用網址**：[https://puti001.github.io/puti-ai-writing-database/](https://puti001.github.io/puti-ai-writing-database/)

---

## 🌟 核心特色

1. **90 題全階梯完整收錄**：
   - 低年級 (1-2年級)：10 篇（約 150 字，看圖說話、生活五感、純真童心）
   - 三年級：20 篇（約 300 字，起承轉合四段啟蒙、具體動態聲音）
   - 四年級：20 篇（約 400 字，動態細節、光影推移、生活省思）
   - 五年級：20 篇（約 500 字，情景交融、借景抒情、層次轉折）
   - 六年級：20 篇（約 600 字，思辨議論、象徵修辭、思想昇華與會考先導）
2. **大屏互動教學模式**：
   - 教室遠視距高對比深色介面，支援 A- / A+ 字體縮放（最大 36px）
   - 審題破題 3 步問（遮蔽/揭示互動搶答）
   - 四段思維心智導圖
   - 雙軌範文對照（普通流水帳抓蟲 vs 特優示範摹寫）
   - 詞彙錦囊一鍵複製、鍵盤左右換題
3. **素養引導單 A4 免排版列印**：
   - 全面移除格子，剛好單頁 A4 濃縮大綱構思
   - 支援直接列印 A4 與一鍵下載 Word (.doc)
4. **一鍵複製 AI 出題提示詞**：
   - 內建師鐸獎名師人設、年級字數規範、四段結構
   - 一鍵複製至 ChatGPT / Claude / Gemini 自行生成更多客製範文
5. **日系暖心 4 大主題切換**：
   - 日系暖陽（預設）、專業湛藍、粉萌櫻花、大地森系
